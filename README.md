# 🛠️ DawaiWaala Admin App

> Administrative Android application developed for the DawaiWaala healthcare commerce platform.

## 📱 About

The **DawaiWaala Admin App** is an internal Android application designed to help administrators manage and monitor important operations across the DawaiWaala platform.

The application provides administrative tools for managing medicines, pharmacies, orders, prescriptions, settlements, and other platform operations.

---

## ✨ Key Features

- 💊 Medicine Management
- 🏪 Pharmacy / Store Management
- 📦 Order Management
- 📋 Prescription Management
- 💰 Settlement Management
- 🚚 Delivery & Order Operations
- 👥 Administrative Controls
- 🔄 Real-time Data Synchronization
- 🔐 Authentication & Access Control

---

## 🛠️ Technology Stack

- **Kotlin**
- **Android Studio**
- **Firebase Authentication**
- **Firebase Realtime Database**
- **Firebase Storage**
- **Material Design**

---

## 🧩 DawaiWaala Ecosystem

The Admin App is one component of the DawaiWaala platform:

| Component | Purpose |
|---|---|
| 📱 User App | Medicine discovery and ordering |
| 🛠️ Admin App | Platform administration |
| 🏪 Seller Dashboard | Pharmacy and seller operations |

---

> ⚠️ This application is intended for authorized DawaiWaala administrators and is not publicly distributed through Google Play Store.
